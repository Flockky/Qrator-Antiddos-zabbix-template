# Zabbix Template: Qrator Labs API Monitoring

Шаблон для мониторинга сервисов, защищенных Qrator Labs, через их API. Шаблон совместим с **Zabbix 7.4**.

## Возможности

*   **Автоматическое обнаружение (LLD):** Автоматически обнаруживает все сервисы (домены/IP), привязанные к аккаунту Qrator.
*   **Метрики трафика:**
    *   Входящий/Исходящий/Пропущенный трафик (bps, pps).
    *   Соотношение входящего к пропущенному трафику (индикатор атаки).
*   **Метрики безопасности:**
    *   Количество заблокированных IP (разделение по источникам: API, WAF, Qrator AntiDDoS).
    *   География блокировок (RU vs Non-RU).
*   **Метрики приложения (L7):**
    *   RPS (Requests Per Second).
    *   HTTP ошибки (4xx, 500, 502, 503, 504 и др.).
*   **Триггеры:**
    *   Обнаружение потенциальных DDoS-атак (резкий рост входящего трафика относительно пропущенного).
    *   Аномальное количество блокировок IP.
    *   Отсутствие L7 трафика (Health-check интеграции с логами).
    *   False Positive блокировки российских адресов в рабочее время.

## Установка

1.  Скачайте файл `template_api_qrator.yaml`.
2.  Импортируйте шаблон в Zabbix:
    *   Перейдите в **Data collection** -> **Templates**.
    *   Нажмите **Import**.
    *   Выберите файл и нажмите **Import**.
3.  Создайте новый хост или отредактируйте существующий.
4.  Привяжите шаблон **API Qrator template** к хосту.
5.  **Важно:** Настройте макросы на уровне хоста (или шаблона):

| Макрос | Описание | Пример значения |
| :--- | :--- | :--- |
| `{$QRATOR.AUTH_TOKEN}` | Ваш API токен Qrator (заголовок `X-Qrator-Auth`) | `319abef39eb82f1e...` |
| `{$QRATOR.CLIENT_ID}` | ID клиента Qrator (часть URL API) | `cl12742` |

> **Где взять данные?**
> *   `CLIENT_ID`: Можно увидеть в URL личного кабинета Qrator или в примерах запросов в документации API.
> *   `AUTH_TOKEN`: Генерируется в настройках профиля Qrator Labs в разделе API.

## Структура данных

Шаблон использует несколько основных точек сбора данных (HTTP Agent), которые затем парсятся через JavaScript preprocessing и Low-Level Discovery:

1.  `qrator_domains_get`: Получает список сервисов, их IP и настройки портов.
2.  `statistics_current_ip`: Основная статистика по трафику (L3/L4) и blacklist.
3.  `statistics_current_http`: Статистика по HTTP запросам и ошибкам.
4.  `statistics_current_locations`: Географическое распределение блокировок.

## Требования

*   Протестировано на Zabbix Server 7.4+
*   Доступность `https://api.qrator.net` с сервера Zabbix.
