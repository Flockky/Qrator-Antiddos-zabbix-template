# Zabbix Template & Grafana Dashboard: Qrator Labs Monitoring

Комплект для мониторинга сервисов, защищенных Qrator Labs. Включает шаблон для **Zabbix 7.4** и готовый дашборд для **Grafana**.

## Состав репозитория

1.  **`zabbox_template.yaml`**: Шаблон Zabbix для сбора метрик через API Qrator.
2.  **`Grafana_dashboard.json`**: Готовый дашборд для визуализации собранных данных в Grafana.

---

## 1. Настройка Zabbix

### Возможности шаблона
*   **Автоматическое обнаружение (LLD):** Автоматически находит все сервисы (домены/IP) в аккаунте Qrator.
*   **Метрики трафика (L3/L4):** Входящий/Исходящий/Пропущенный трафик (bps, pps), соотношение трафика (индикатор атаки).
*   **Безопасность:** Количество заблокированных IP (WAF, AntiDDoS, API), география блокировок (RU/Non-RU).
*   **Метрики приложения (L7):** RPS, HTTP ошибки (4xx, 5xx).
*   **Умные триггеры:**
    *   Детекция DDoS (резкий рост входящего трафика).
    *   Аномалии в количестве блокировок.
    *   Контроль доставки логов (Health-check L7 трафика).
    *   Alerting по FP блокировкам российских адресов.

### Установка
1.  Импортируйте `zabbox_template.yaml` в Zabbix (**Data collection** -> **Templates** -> **Import**).
2.  Привяжите шаблон к хосту (можно создать пустой хост-контейнер, если не нужен агент).
3.  **Обязательно задайте макросы** на уровне хоста:

| Макрос | Описание | Где взять |
| :--- | :--- | :--- |
| `{$QRATOR.AUTH_TOKEN}` | API Token Qrator | ЛК Qrator -> Профиль -> API |
| `{$QRATOR.CLIENT_ID}` | ID клиента (например, `cl12742`) | URL ЛК Qrator или документация API |

## 2. Настройка Grafana

Дашборд `Grafana_dashboard.json` построен на основе данных, собираемых Zabbix-шаблоном.

### Требования
*   Установленный плагин **[Alexander Zobnin Zabbix datasource]**.
*   Настроенный Data Source "Zabbix" в Grafana, подключенный к вашему Zabbix API.

### Импорт
1.  В Grafana перейдите в **Dashboards** -> **Import**.
2.  Загрузите файл `Grafana_dashboard.json` или вставьте его содержимое в поле JSON.
3.  Выберите подключенный Zabbix Data Source.
4.  Наслаждайтесь визуализацией! 📊

### Особенности дашборда
*   Переключатель сервисов (Variable) для выбора конкретного защищаемого ресурса.
*   Панели с трафиком (bps/pps) и ошибками HTTP.
*   Визуализация активных блокировок и географии атак.
